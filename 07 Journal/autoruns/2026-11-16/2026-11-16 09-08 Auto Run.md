## Decisions I took

- **Field of view in degrees.** The inspector drags it at 0.1 a step, so degrees are what a person
  types. Default 60°.
- **Exposure is EV100, default 0.** The frame is scaled by `1 / (1.2 * 2^EV100)`, so 0 leaves a
  base-color-only frame close to unscaled.
- **`main` defaults to true.** A camera added from the inspector draws at once, and a second one
  changes nothing, because the first in hierarchy order still wins.
- **Near 0.1 and far 1000 by default.**
- **The warn-once flag belongs to the caller** (`bool& warnedNone`), and finding a camera clears
  it. The function stays stateless, each view keeps its own flag, and a scene that loses its camera
  again warns again.
- **A new `core/camera/` folder**, beside `mesh/`, because the apps register `Camera` like
  `MeshRenderer`. It is not a built-in like `Transform`.
- **No custom inspector widget.** The generic rows already show and edit floats and bools.
