## Decisions I took

1. **Export is a `std::function` on `PanelsManager`, and `EditorApp` submits the command.**
   `EditorCommands` holds none of the `Project`, the `AssetIndex` or a non-const registry.
2. **A protected `EditorApp::makeExportCommand()`** lets the editor's tests apply the export
   the way the probe already applies a save.
3. **A missing runtime returns the plain `FileError::NotFound`**, with a log line that names
   the path. No `ProjectError` value was added.
4. **The runtime's file name comes from CMake** (`$<TARGET_FILE_NAME:runtime>`) rather than
   from a guessed `.exe` suffix.
5. **`TE_EDITOR_DEFAULT_PROJECT_ROOT` moved to `te_editor_objects` as PUBLIC**, so a test can
   export `projects/dev` and open it the way the runtime does.
6. **`EditSession::hasUnsavedEdits()`** was added, so the unsaved-edits warning is decided on
   the simulation thread, not from the main thread's snapshot, which can be one edit behind.
