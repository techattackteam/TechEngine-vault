## Decisions I took

- **The header is `core/mesh/Mesh.hpp`, in a new folder.** `resources/` holds the cache and
  pack machinery, not the types it loads; the scene asset sits in `scene/` the same way.
- **`Mesh` is both the cache payload and the asset**, with `write` and `read` as members and
  the id as a field. This copies `SceneAsset`'s shape.
- **Positions are `std::vector<Vec3>`**, written as one bulk span. A `static_assert` pins
  `Vec3` to three packed floats, so a GLM setting cannot change the file format silently.
- **`read` rejects an index past the last position, and an index count that is not whole
  triangles, as `Malformed`.** Otherwise a bad index would reach R1's draw call.
- **`read` assigns the mesh only on success**, like `SceneAsset::read`.
- **The loader names no dependencies.** A mesh references nothing until R1 adds materials.
- **The magic is "TEMS", and a mesh file is `.temesh`.** Only a test uses the extension so
  far; the index reads the magic, not the extension.

None of these changes a *Decided* row or needs an ADR. At `/card-close`, the folder and the
validation rules belong in [[Resources - Design]] § *Reference fields*, under *The mesh*.
