# 2026 Q4: Close the Chain, Open the Lanes

**Theme:** finish the last chain rung, then make the engine visible again, starting with
the editor.

Q3 built the chain from M0 to M5 ([[2026-Q3]]). The engine now simulates, schedules,
delivers events and input, and draws a triangle, but there is nothing to look at and no way
to author content. Q4 closes M6 so that the engine has content to load, then brings the
editor back on top of it. The [[Roadmap]] owns the order; this note sets the direction.

## Q4 objectives

1. **M6 closed.** Resources and content packs have accepted ADRs and a design note
   ([[Resources - Design]]), and a project names a
   scene that the runtime loads. This is the last rung written against the chain's
   irreversibility rule, so it is decided before it is built.
2. **The editor is up and running again.** T1 starts on top of M6: the editor opens a
   project, shows its Scene, and lets you inspect it. How ImGui shares the window and the
   threads ([[Window - Design]] § *Open questions*) is decided before the first panel.
3. **The renderer lane is unblocked.** R1's renderer ADR is drafted, so that the first real
   renderer has a decision to build against when the editor needs a viewport.
